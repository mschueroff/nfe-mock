# Histórico de mudanças

As mudanças estáveis relevantes do NF-e Mock são registradas neste arquivo.
Mudanças beta são publicadas nas prereleases do GitHub e consolidadas aqui
quando promovidas para uma versão estável.

O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e
as versões seguem o [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## 0.1.0 - 2026-09-13

### Adicionado

- Primeira versão pública do gerador local de XML NF-e 4.00, chave de acesso e DANFE.
- Entidades unificadas, produtos reutilizáveis e cadastro de CFOP por operação.
- Suporte a emitente pessoa física para cenários de produtor rural.
- Persistência SQLite, sequências, recuperação e execução com Docker.
