# Política de segurança

## Versões suportadas

Correções de segurança são aplicadas à release estável mais recente. Quando
viável, a correção também será incluída na linha beta atual.

## Relato de vulnerabilidade

Use **Security → Report a vulnerability** no repositório GitHub. Esse recurso
usa o GitHub Private Vulnerability Reporting e mantém o relato fora das issues
públicas. Informe versões afetadas, passos de reprodução, impacto e possíveis
medidas de correção.

Não inclua CPF/CNPJ reais, XML fiscal, certificados, tokens ou outros secrets.
Não abra uma issue pública para uma vulnerabilidade ainda sem correção.

Os mantenedores responderão pelo GitHub, avaliarão o impacto e coordenarão a
correção e a divulgação. O projeto não publica endereço de e-mail pessoal.
